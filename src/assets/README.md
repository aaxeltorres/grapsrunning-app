# Assets

Placeholder folder for image and icon assets (`logo.png`, app icons, splash
image, provider marks for Google/Apple, feature icons, etc.).

No binary assets are included in this beta pass — all icon/logo spots in the
UI are rendered with `IconPlaceholder` (see `src/components/IconPlaceholder.tsx`)
so the layout is final while the visual assets are still pending.

Drop final files here using this suggested naming:

- `logo.png` / `logo@2x.png` / `logo@3x.png`
- `icon-coach.png`, `icon-routes.png`, `icon-plan.png`, `icon-stats.png`
- `icon-google.png`, `icon-apple.png`
- `icon-heartbeat.png`, `icon-flame.png`, `icon-clock.png`, `icon-steps.png`
